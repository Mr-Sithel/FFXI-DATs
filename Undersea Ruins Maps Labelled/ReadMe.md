### Labelled Remapster Maps for Alzadaal Undersea Ruins 

Has all the text locations to get around in the areas. Never get lost again!
- These the 1024 version maps.

### Install using Piviot

If on Horizon, path is:
- HorizonXI\Game\polplugins\DATs

* Options to where these can go.
    - Overwrite current Remapster maps. (copy over the ROM folder and replace all)
    - Overwrite current labelled maps. (copy over the ROM folder and replace all)

* Copy to a new folder in the DATs location and make sure its enabled in the launcher.
- HorizonXI\Game\polplugins\DATs
```
Undersea Ruins Maps Labelled
└── ROM
    ├── 284
    │   ├── 99.dat
    │   ├── 100.dat
    │   ├── 101.dat
    │   ├── 102.dat
    │   └── 103.dat
    └── 285
        ├── 0.dat
        ├── 1.dat
        ├── 2.dat
        ├── 3.dat
        ├── 4.dat
        ├── 5.dat
        └── 6.dat
```


If you use a new location make sure these are above any other maps for priority or these won't show.
* Type /pivot in game to check priority.
